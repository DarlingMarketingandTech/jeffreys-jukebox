# Jeffrey's Jukebox — Audio Catalog

Last updated: 2026-09-10

This file tracks the real recordings currently wired into the jukebox and the remaining source material that should be normalized before publication.

## Production catalog rules

- No generated/fake title cards.
- Keep one canonical copy of obvious duplicates.
- Prefer MP3/M4A source files for immediate browser playback.
- Keep large WAV/FLAC files in Drive until they are normalized to a web-ready master.
- Preserve the original five Jeffrey Taylor recordings.
- Google Drive is the source archive; dedicated media delivery remains the preferred long-term production layer.
